# Як опублікувати сайт на GitHub (покроково)

Потрібен лише браузер і акаунт на github.com. Усе безкоштовно.

## 1. Створіть репозиторій

1. Увійдіть на github.com, натисніть **+** → **New repository**.
2. **Repository name:** наприклад `flyon`.
3. Оберіть **Public** (для безкоштовного GitHub Pages репозиторій має бути публічним).
4. **Нічого не ставте** в «Add a README», «.gitignore», «license». Натисніть **Create repository**.

## 2. Завантажте файли

### Варіант А: через браузер (найпростіше)

1. Розпакуйте `flight-weather.zip` на комп'ютері.
2. На сторінці порожнього репозиторію натисніть посилання **uploading an existing file**.
3. Перетягніть у вікно **весь вміст** розпакованої папки: `index.html`, `app.js`, `style.css`, `README.md`, `.gitignore` та папки `config`, `scripts`, `tests`, `docs`, `.github`.
4. Внизу натисніть **Commit changes**.

**Перевірте папку `.github`.** Файли й папки з крапкою на початку приховані: на Mac у Finder натисніть `Cmd + Shift + .`, на Windows у Провіднику увімкніть «Показати приховані елементи». Після завантаження в репозиторії має бути шлях `.github/workflows/update-forecast.yml`. Якщо його немає:
1. Натисніть **Add file → Create new file**.
2. У полі імені введіть `.github/workflows/update-forecast.yml` (слеші створять папки).
3. Вставте вміст файлу з архіву й натисніть **Commit changes**.

### Варіант Б: через git у терміналі

```
cd flight-weather
git init
git add .
git commit -m "Перша версія"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/flyon.git
git push -u origin main
```

## 3. Увімкніть GitHub Pages

1. У репозиторії відкрийте **Settings → Pages**.
2. У розділі **Build and deployment** у полі **Source** виберіть **GitHub Actions**.

## 4. Запустіть перше оновлення

1. Відкрийте вкладку **Actions**. Якщо GitHub просить дозволити запуск, погодьтеся.
2. Зліва оберіть **Оновлення прогнозу** → справа **Run workflow** → **Run workflow**.
3. Зачекайте 1–2 хвилини, поки обидва кроки (`build`, `deploy`) стануть зеленими.
4. Адреса сайту: `https://ВАШ_ЛОГІН.github.io/flyon/`. Її також видно в **Settings → Pages**. Саме це посилання передавайте іншим.

Далі сайт оновлюватиметься сам кожні 6 годин (близько 02:37, 08:37, 14:37 і 20:37 за Києвом узимку, а влітку на годину пізніше, бо розклад задано за UTC; GitHub інколи запізнюється на кілька хвилин).

## Якщо щось пішло не так

- **Сторінка пише «Дані ще не завантажені»:** перше оновлення ще не завершилось або впало. Перевірте вкладку Actions.
- **Червоний хрестик у Actions:** відкрийте невдалий запуск, натисніть на крок із помилкою і скопіюйте текст. Найімовірніша причина: Open-Meteo відхилив якийсь параметр. Надішліть мені цей текст, виправлення займе кілька хвилин.
- **Тести впали:** повідомлення скаже, у якому файлі в `config/` помилка (наприклад, оптимальний вітер більший за максимальний).
- **Автооновлення зупинилось:** GitHub вимикає заплановані запуски у публічних репозиторіях, де 60 днів не було жодних змін. Зайдіть у Actions і натисніть **Enable workflow**, або внесіть будь-яку правку у файл.

## Спільна робота

- Посилання на сайт може відкрити будь-хто.
- Змінювати код і конфіги можете лише ви. Інші можуть запропонувати правку через **Fork** і **Pull request**, а ви її погодите. Щоб дати людині пряму можливість редагувати, додайте її в **Settings → Collaborators**.
- Репозиторій публічний, тож його вміст (точки, назви й межі літаків із `config/`) бачитиме будь-хто з посиланням.

## Як змінити пороги чи додати літак

Відкрийте потрібний файл у `config/` на GitHub, натисніть олівець (Edit), змініть число й натисніть **Commit changes**. Сайт перепублікується сам протягом хвилини. Докладніше в README.
