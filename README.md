# FlyOn: погода для польотів

Сайт показує, чи підходить прогноз погоди для польотів малих безпілотників за їхніми ТТХ: на сьогодні, завтра й тиждень, по годинах, з вікнами сприятливої погоди від 4 годин. Є перемикач літаків, точок (Великий Бурлук, Вовчанськ, Мілове, Піщане) і режим «Весь район».

> Це допоміжний інструмент для планування малої безпілотної авіації. Дані: прогнозна модель Open-Meteo, не офіційний авіаційний метеопрогноз. Підошва хмар і висота обмерзання є оцінками. Рішення про виліт ухвалює оператор.

## Як це працює

1. Кожні 6 годин (GitHub Actions) скрипт `scripts/fetch_forecast.py` бере прогноз Open-Meteo для всіх точок і зводить його до висот 100, 550, 750, 1000, 1500, 2000, 2500, 3000 м над землею.
2. `scripts/evaluate.py` порівнює кожну годину з ТТХ кожного літака й рахує колір години та вікна.
3. Сторінка (`index.html`, `app.js`, `style.css`) показує результат. Сайт публікується на GitHub Pages, інструкція в [docs/GITHUB.md](docs/GITHUB.md).

## Як рахується висота польоту («шар підйому»)

Літак піднімається від землі, тому вітер, вологість і температура мають бути в межах ТТХ **на кожному рівні від землі до робочої висоти**. Рівні вище робочої висоти не обов'язкові.

- **Робоча висота** = мінімальна висота хмар з ТТХ, округлена до найближчого рівня: Лелека 800 м → 750 м, Фурія 600 м → 550 м.
- **Стеля** = найвищий рівень, до якого все в межах ТТХ на кожному рівні знизу. Політ можливий у шарі від робочої висоти до стелі.
- Година червона, якщо порушення є вже в шарі до робочої висоти. Якщо порушення лише вище, година придатна, а сторінка пише «Політ можливий у шарі 750–1000 м» і показує в колонці «Політ до» стелю.
- Коли стеля збігається з робочою висотою, з'являється попередження «Вузький шар».
- Пориви на землі, опади, туман, видимість і підошва хмар стосуються всієї години й не залежать від шару.

## Кольори годин

| Колір | Значення |
|---|---|
| Зелений | Усе в межах оптимуму |
| Жовтий | Вітер між оптимальним і максимальним у шарі до робочої висоти; сніг (з підказкою «сніг крупою» чи «сніг, перевірте тип візуально») |
| Червоний | Вітер вище максимуму, вологість понад 90 % чи температура поза межами в шарі до робочої висоти; пориви на землі вище межі; підошва хмар нижче мінімуму; дощ понад 0,1 мм/год; туман або видимість менше 2000 м; мокрий сніг |
| Сірий | Немає даних для оцінки |

Обмерзання, близька до порогу підошва хмар і низька достовірність (з 4-го дня) показуються як **попередження** й колір не змінюють.

## Що де змінювати

Усе налаштовується у файлах `config/`, код змінювати не треба.

**Додати літак.** Скопіюйте `config/aircraft/furiya.json`, дайте новий `id` і `name`, змініть значення в `limits`:

```json
{
  "id": "nazva-litaka",
  "name": "Назва літака",
  "order": 3,
  "limits": {
    "temp_c": { "min": -30, "max": 50 },
    "wind_ms": { "optimal": 8, "max": 10 },
    "gust_ground_ms": { "max": 10 },
    "humidity_pct": { "max": 90 },
    "cloud_base_m": { "min": 600 }
  }
}
```

`order` задає порядок кнопок (менше число значить лівіше). Вітер вимірюється в м/с, висоти в метрах над землею.

**Змінити правила.** `config/rules.json`: висоти, мінімальна тривалість вікна (`window_min_hours`), межа дощу, видимість для туману, коди снігу. Щоб сніг завжди був червоним, перенесіть коди з `snow_codes_yellow` і `snow_grains_codes_yellow` у `wet_snow_codes_red`.

**Змінити точки.** `config/locations.json`: назва, широта, довгота. Точка з `null` у координатах пропускається.

## Запуск на своєму комп'ютері

Потрібен лише Python 3.9+ (сторонні пакети не потрібні).

```
python scripts/fetch_forecast.py
python scripts/evaluate.py
python -m http.server 8000
```

Далі відкрийте `http://localhost:8000`. Тести логіки: `python -m unittest discover -s tests -v`.

## Обмеження

- Моделі точні лише приблизно, вітер на висотах далі ніж 3–4 дні грубий.
- Open-Meteo не віддає підошву хмар напряму, вона оцінюється за вологістю профілю та рівнем конденсації (похибка ±100 м і більше).
- Вологість понад 90 % у шарі до робочої висоти (там, де зазвичай хмари й імла) узимку часто дає червоні години. Це наслідок ТТХ, а не помилка.
